## Index files

A file named `index` or `README` inside a folder becomes that folder's page. It
is not listed as a separate child.

## Nesting

Folders nest arbitrarily deep. The sidebar shows a window of levels rather than
the whole tree, so a deep branch stays navigable; `depth` in the root
`config.yml` sets how many levels that window spans.
